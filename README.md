# Мои финансы

Личное веб-приложение (PWA) для учёта доходов, расходов, долгов и баланса.
По умолчанию все данные хранятся **только на вашем устройстве** (IndexedDB в
браузере), без сервера и аккаунта. Аккаунт с логином/паролем — необязательный
шаг (Настройки → Аккаунт): заведите его, только если хотите видеть одни и те
же данные на нескольких устройствах — тогда операции/долги/счета/платежи
синхронизируются через сервер (Cloudflare Worker + D1). PIN-код, тема, язык и
валюта в любом случае остаются только на конкретном устройстве.

## Возможности

- Доходы и расходы с категориями, заметками и датой.
- Долги в обе стороны («мне должны» / «я должен») с частичными платежами,
  сроком возврата и историей погашений.
- Текущий баланс, разбивка расходов по категориям, график доходов/расходов
  по месяцам.
- Единая история всех операций с поиском и фильтрами.
- Несколько счетов («Личное», «Бизнес» и любые свои) с балансом по каждому и
  переводами между ними.
- Интерфейс на русском и казахском языках — переключается в любой момент в
  Настройках → Язык.
- Экран блокировки с PIN-кодом (Настройки → Экран блокировки).
- Регулярные обязательные платежи (кредиты, тарифы, подписки) с напоминанием
  к дню оплаты — вкладка «Платежи». При добавлении можно выбрать поставщика
  из каталога (операторы связи, интернет, коммуналка, банки, подписки) с
  поиском или ввести свой вариант вручную.
- Свои категории (иконка + цвет), выбор валюты, светлая/тёмная тема.
- Экспорт всех данных (операции по каждому счёту отдельным листом, долги,
  платежи, счета) в настоящий файл .xlsx одной кнопкой (Настройки → Данные) —
  открывается в Excel, на телефоне в Office/Numbers и в Google Таблицах; это
  копия для просмотра и хранения, восстановление данных обратно в приложение
  из файла не предусмотрено.
- Работает офлайн и устанавливается на телефон как приложение (Add to Home
  Screen / «Установить приложение»).
- Часовые push-напоминания «загляните в приложение» (Настройки → Часовые
  напоминания) — работают, даже когда приложение закрыто, через Web Push;
  нужно установить приложение на экран «Домой» и разрешить уведомления.
- Необязательный аккаунт (Настройки → Аккаунт) для синхронизации данных между
  устройствами по логину/паролю.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`) в браузере
телефона или компьютера. Чтобы установить как приложение на телефоне —
откройте сайт в браузере и выберите «Добавить на экран «Домой»»
(Android/Chrome) или «На экран «Домой»» (iOS/Safari).

## Сборка для продакшена

```bash
npm run build   # собирает dist/ — статические файлы, готовые для любого хостинга
npm run preview # локально проверить продакшен-сборку
```

Собранный `dist/` — обычный набор статических файлов: его можно разместить
на любом хостинге (Netlify, Vercel, GitHub Pages, собственный сервер) без
какой-либо серверной части.

## Портативная версия (один файл)

Если нужно просто передать приложение файлом (например, через Telegram) без
хостинга — есть сборка в один самодостаточный HTML-файл со всем кодом внутри:

```bash
npm run build:portable   # собирает dist-portable/portable.html
```

Этот файл можно отправить как обычный документ и открыть прямо на телефоне.
Работает полностью (все данные, графики, долги), но у него нет service
worker и install-меню «Добавить на экран «Домой»» в полноценном виде — это
ограничение браузеров для файлов, открытых не с сервера. Лучше всего
работает при открытии в Chrome на Android; на iPhone Safari не всегда
запускает локальный HTML-файл как страницу — для iPhone надёжнее вариант
с хостингом (см. «Сборка для продакшена» выше).

## Иконки приложения

Иконки лежат в `public/` и сгенерированы из `public/icon-source.svg` /
`public/icon-maskable-source.svg`. Чтобы поменять иконку — отредактируйте
эти SVG и перезапустите:

```bash
node scripts/gen-icons.mjs
```

## Технологии

React + TypeScript + Vite, Dexie (IndexedDB), React Router, Recharts,
vite-plugin-pwa.
